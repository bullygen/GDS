твоя задача - по описанию задачи из хакатона собрать нейронную сеть гдс для работы с планировщиком управления космическом группировкой, которая может выполнять три действия на каждом аппарате. 

Доступные ресурсы:
- Полное опеисание задачи на языке сети gds содержится в файле hackathon/HACKATON.md, где в том числе содержатся инструкции по i\o, необходимой архитектуре сети gds и прочим важным вещам, которые надо сохранять и строить на графиках
- Примеры сценариев в жсонах и все необходимые данные (например, временные ряды, реестр заявок, экстренные сообщения) содержатся по адресу hackathon/data.
- Модельный интерперетатор жсонов из сценария содержится по адресу hackathon/model

Конечный результат - питон скрипты и построитель gds сети в папке hackathon/solver, который делает сеть, компилирует ее, принимает на вход данные из жсонов (реестр заявок, сообщения, данные среды и начальные состояния аппаратов), составляет корректное расписание, а потом оптимизирует по выдарнному варианту с помощью генетического алгоритма:
- максимизация количества заданий приоритета 3 (наивысший)
- максимизация прибыли
- парето фронт по 2 предыдущим переменным

Это все должно быть доступно к управлению в виде питон скрипта, в котором можно было бы выбирать аргументы (что читать, что делать, кужа сохранять результат). Одновременно с этим построй графики расписания, ресурсов и промежуточных переменных, которые указаны в разделе 11 hackathon/HACKATON.md
