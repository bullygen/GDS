При восстановлении истории повторён исходный GDE3 с теми же параметрами;
проверено совпадение всех оценок, кроме времени, и всех финальных планов.
Для каждого снимка фронт независимо сопоставлен только с кандидатами,
оценёнными к этому поколению, а кривая прогресса — с накопленным максимумом.
Сохранение при новых запусках проверено для всех трёх целей, нулевого
числа поколений и `--no-plots`. Тест с появлением новой доминирующей точки
подтверждает, что снимок начального поколения не подменяется финальным.
Отдельно проверен неопределённый процент при отсутствии приоритетных заявок.

Графики просмотрены: нет искусственного роста при отсутствии улучшений,
а максимум каждого критерия при Парето подписан как независимый максимум.
Все кадры одной версии используют одинаковые пределы осей.

## Производительность

Измерения `benchmark.py` выполнены локально на Intel Core 5 210H в Release,
Python 3.12.3, GCC 13.3.0. Файл измерений: `hackathon/solver/outputs/benchmark.json`.
Для декодирования использованы один случайный геном, `seed=42`, `attempts=4`.
Пересчёты физики усреднены по трём повторениям.

| Сценарий | Построение сети, с | Один GDS-кандидат, с | Число полных проверок предложений | C++ inspect, с | Python Session, с |
|---|---:|---:|---:|---:|---:|
| P01_intro | 0.0013 | 0.00013 | 10 | 0.000040 | 0.00486 |
| P02_shift | 0.0102 | 0.169 | 1442 | 0.000735 | 0.1030 |
| P03_energy | 0.0094 | 0.316 | 2856 | 0.000703 | 0.1037 |
| P04_demand | 0.0414 | 1.899 | 5975 | 0.001224 | 0.2521 |

`native inspect` возвращает полные массивы граничных состояний;
Python `Session` также строит словари трассы, проверяет входы и регистрирует
команды. Это сравнение двух путей исполнения, а не изолированное ускорение
арифметических формул. Внутри GDS-предложений нет переходов в Python.
Во время исполнения Python используется для независимого контроля и отчётов.

Полный проверочный прогон одного режима, включая независимую проверку,
CSV, PDF и PNG всех аппаратов, занял около 9 секунд для P01, 30–37 секунд
для P02/P03 и 67–71 секунды для P04. Эти времена зависят от машины и нагрузки;
`--no-plots` позволяет исключить стоимость отрисовки при исследовании поиска.
